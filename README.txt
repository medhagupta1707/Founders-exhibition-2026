Before publishing
1. Replace social links in index.html: search for data-placeholder="youtube", "facebook", "instagram", "x", and "linkedin" and change each href="#" to the official URL.
2. Replace venue placeholders with confirmed locations.
3. Add approved real product photographs and confirmed prices as they become available.
4. The promotional banner image is illustrative artwork. Its QR-looking graphic is NOT a working QR code. Generate a separate QR code after the site has a public URL.
5. Upload all files together to a public static host. Keep the image files beside index.html so relative image paths work.
